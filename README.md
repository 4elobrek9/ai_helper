# LUMI AI

LUMI — локальный голосовой помощник с чатом, озвучиванием ответов и базовым управлением компьютером.

## Запуск на Windows

1. Установите Python 3.11 и [Ollama](https://ollama.com/). Установщик Python должен добавить команду `py` в Windows.
2. Запустите `launch.bat`. Скрипт создаст отдельную `.venv311` на Python 3.11, установит зависимости и откроет GUI.
3. В настройках выберите **Ollama (локально)**. Приложение автоматически ищет установленные модели при запуске; для повторного поиска нажмите **Обновить список моделей Ollama**. Для автоматического выбора достаточно оставить модели в положении **Авто**.
4. Настройки покажут объём RAM и (если доступна `nvidia-smi`) видеопамяти NVIDIA, а также подберут модели для чата и анализа экрана примерно под 60% доступной памяти. В каталоге можно выбрать и скачать Qwen2.5/Qwen2.5-VL от компактных до крупных вариантов; загрузка `ollama pull` откроется в отдельном окне CMD. Оценки памяти приблизительны, а на компьютерах без NVIDIA приложение ориентируется на системную RAM. На компьютере с менее чем 8 ГБ RAM и менее чем 4 ГБ VRAM приложение рекомендует для чата облачный **Mistral API**; для локальной попытки предлагается компактная `qwen2.5:1.5b`. Облачный режим требует собственного ключа и отправляет текстовые запросы поставщику.

При запуске LUMI заранее загружает локальную модель faster-whisper (`base` на ПК с менее чем 10 ГБ RAM, иначе `small`) и калибрует микрофон в фоне, чтобы голосовое управление было готово к нажатию кнопки микрофона. Для первой загрузки модели нужен интернет, ключ не нужен; пока подготовка не завершена, приложение сообщит об этом при попытке активации. Аудио после загрузки модели распознаётся на компьютере и не отправляется в Google или другой облачный сервис. Для более быстрой обработки включены int8, VAD и beam size 1; при проблемах с точностью можно задать `LUMI_WHISPER_MODEL=small` или `medium` до запуска. В настройках Windows проверьте разрешение доступа к микрофону для классических приложений и выберите тот же физический микрофон, который используется в системе.

В режиме без Porcupine можно включить локальное распознавание слова «Люми» — оно работает через Whisper без облачного API, но требует больше CPU, чем специализированная wake-word модель. После wake-word LUMI сразу слушает следующую фразу и не ждёт длинного голосового подтверждения. Распознавание речи с низкой вероятностью наличия речи отфильтровывается, чтобы уменьшить ложные фразы из тишины. Ответы озвучиваются локально через Silero, Piper или системный голос. Piper устанавливается в отдельном окне навыков: русские модели скачиваются только по кнопке, проверяются по контрольным суммам и остаются на компьютере. Во время ответа можно нажать кнопку остановки в чате или сказать «стоп»/«отмена».

Логи сохраняются в `log\lumi.log` рядом с приложением; при отсутствии прав на запись используется `%LOCALAPPDATA%\LumiAI\log\lumi.log`. Файл ротируется при достижении 5 МБ, хранятся до пяти архивов. Переменная `LUMI_LOG_DIR` позволяет задать другое расположение; путь к файлу записывается в начале журнала.

Команда «какая погода в Москве?» запрашивает Open-Meteo для названного города. Если город не произнесён, LUMI определяет его по IP через ipinfo; погода требует интернета, но API-ключ не нужен.

### Локальный wake-word: проекты и ограничения

- [openWakeWord](https://github.com/dscripka/openWakeWord) — открытый локальный детектор с потоковой обработкой небольшими аудиофреймами и обучением собственных фраз. В README проекта указано, что готовые модели пока поддерживают только английские фразы; для слова «Люми» потребуется отдельная обученная модель.
- [sherpa-onnx](https://github.com/k2-fsa/sherpa-onnx) — локальный стек для Windows с распознаванием речи, VAD и keyword spotting; потребуется подходящая модель ключевого слова.
- [faster-whisper](https://github.com/SYSTRAN/faster-whisper) — текущий локальный STT LUMI. Проект документирует VAD и CPU/GPU quantization; для CPU рекомендует int8 как способ сократить память и ускорить обработку.
- [SpeechRecognition](https://github.com/Uberi/speech_recognition) — документация уточняет, что имя микрофона и его индекс PyAudio должны соответствовать друг другу; здесь выбираемый в настройках микрофон теперь передаётся обоим аудиопотокам.

Сейчас LUMI не устанавливает сторонние wake-word пакеты или модели автоматически: пока не добавлена и не проверена русская модель для «Люми», приложение использует локальное распознавание команд либо Porcupine, если пользователь его настроил. Чтобы устранить частые проблемы с пустой транскрипцией, при запуске калибруется выбранный микрофон, а wake-word поток освобождает устройство перед записью команды.

## Экран и управление

- Кнопка с изображением глаза в чате отправляет снимок выбранного экрана найденной локальной vision-модели Ollama. Основной монитор выбирается автоматически; монитор можно сменить в настройках. Снимок не отправляется в Mistral или другие облачные сервисы.
- Локальный OCR EasyOCR используется для поиска текста при голосовых командах управления курсором и загружает свои модели при первом использовании.
- Голосовые команды «наведи на …» и «нажми на …» ищут текст на экране и перемещают курсор или выполняют один щелчок.
- Команда «прочитай текст на экране» использует локальный OCR EasyOCR и озвучивает найденный текст.
- Команды «что на экране?» и «прочитай экран» отправляют снимок экрана локальной vision-модели Ollama.

Снимок экрана используется только для ответа на запрос и не сохраняется в истории чата. Локальная модель может пользоваться инструментами для просмотра экрана, запуска разрешённых приложений, щелчка по найденной надписи, ввода текста и ограниченного набора клавиш. Инструменты вызываются только по явной просьбе пользователя; команды запуска программ ограничены белым списком. Запросы вроде «открой YouTube и найди собак», «поищи собак на YouTube» и «введи собак в поиске YouTube» обрабатываются отдельным локальным маршрутом. Общий веб-поиск открывает Google в браузере по умолчанию, а Яндекс Маркет остаётся отдельным инструментом товарного поиска. Для сравнения товаров LUMI может последовательно просматривать результаты и видимые страницы через локальный OCR, но должна указывать только фактически найденные цены и характеристики. Можно попросить открыть публичную HTTP/HTTPS-ссылку, осмотреть страницу, нажать на видимый безопасный элемент или прокрутить её. Управление Steam позволяет открыть Steam, найти страницу в магазине или запустить уже установленную игру по названию; Windows Settings открываются только в разрешённых разделах. Вход в аккаунты, ввод паролей, отправка форм, покупка и оплата автоматически не выполняются. LUMI никогда не исполняет произвольный текст модели в CMD или PowerShell; если модель не вызывает инструмент для явной команды, приложение сообщает, что действие не выполнено. При выбранном Mistral команды управления компьютером и браузером всё равно обрабатываются локальной Ollama; обычные текстовые запросы продолжают идти выбранному провайдеру. Ответ ассистента постепенно появляется в чате и после завершения сохраняется в истории.

Файлы журналов хранятся в `log`: `lumi.log` для главного окна, `chat.log` для отдельного чата и `skills.log` для отдельного окна навыков. Разделение не позволяет ротации логов разных процессов мешать друг другу. Для запроса «найди лучший телевизор до 40к» LUMI открывает выдачу по телевизорам до 40 000 рублей, затем старается открыть и сверить OCR не менее трёх отдельных карточек; если страницы или цены не читаются, она сообщает, что сравнение не подтверждено.

## Навыки и оформление

Кнопки чата и навыков открывают отдельные небольшие окна Windows, которые можно перемещать, сворачивать и закрывать независимо от главного окна. В чате кнопка слева сверху раскрывает анимированный список бесед; можно создать отдельный чат, переключиться между ними, очистить историю текущего чата или удалить отдельную беседу. Контекст сообщений разных чатов изолирован; общий голосовой диалог хранится отдельно. В окне навыков встроенные команды собраны в одну группу; шестерёнка открывает перечень команд с примерами использования и отдельными переключателями. Там же можно включить или отключить **«Перебивать голосом»**: во время генерации микрофон принимает короткую фразу до 2,2 секунды, после распознавания Whisper останавливает озвучивание и генерацию, затем фраза обрабатывается как новая команда. Голоса Piper находятся в разделе «Навыки от разработчика». Там же можно скачивать новые возможности и добавлять собственные навыки. Пользовательские навыки с инструкциями сохраняются локально; по желанию к ним можно привязать локальный `.exe`, который запускается только по явной просьбе. Инструкции навыка сами по себе не дают разрешения на действия с компьютером.

В каталоге разработчика доступен **ScreenSage**. Он скачивается в `MODS\ScreenSage_WIN.exe` только после нажатия кнопки; во время скачивания отображаются прогресс и размер, перед установкой проверяется SHA-256 по метаданным GitHub Releases, размер и формат EXE. После установки программу можно запустить вручную, удалить или включить её запуск вместе с LUMI отдельным переключателем. Это сторонняя программа: проверьте страницу проекта и учитывайте предупреждения Windows перед первым запуском.

Команда «какие команды есть?» или «что ты умеешь?» перечисляет встроенные команды, которые включены в настройках навыков. Из коробки доступны погода, OCR текста/элементов экрана, анализ экрана, Google-поиск и управление браузером, Steam, разрешённые разделы настроек Windows, открытие встроенных приложений и ограниченный набор клавиш. Во время активного ответа голосовое прерывание анализирует короткие фрагменты аудио (до 2,2 секунды), чтобы быстрее остановить озвучивание и обработать новую команду. Если Silero или выбранный Piper не может создать аудио, LUMI записывает ошибку и пробует системный голос Windows. «Стоп» и «отмена» остаются доступны всегда. Системный промпт из настроек читается из общей базы при каждом новом запросе, поэтому после сохранения он применяется без перезапуска; в запросе он передаётся первым системным сообщением, перед историей диалога. Если в настройках выбран **Ollama (локально)**, LUMI при запуске проверяет локальный HTTP-сервер и пытается запустить `ollama serve`, если он недоступен. Если Ollama не установлена или сервер не стартует, причина попадёт в лог и появится в уведомлении.

Главное окно и панели используют затемнённые полупрозрачные стеклянные слои, мягкие контуры и анимации раскрытия/пульсации. Крестик закрывает отдельные окна чата и навыков, а пункт **Выход** в меню системного трея завершает LUMI вместе с запущенными ею окнами.

## Окно и трей

Сворачивание и закрытие главного окна скрывают его в системный трей и убирают из панели задач. Выберите **Развернуть LUMI**, чтобы вернуть окно, или **Выход**, чтобы полностью закрыть приложение. Окно навыков — отдельный процесс с собственным окном; его закрытие не закрывает LUMI.

Для сборки Windows EXE запустите `build_exe.py`; главное окно, отдельные окна чата и навыков, EXE и трей используют `app_icon.ico`.

## Примечания

- Для локального чата Ollama должна быть запущена. При выборе **Авто** LUMI находит загруженные модели через Ollama и выбирает одну для чата и отдельную модель с поддержкой изображений для анализа экрана. Можно также выбрать конкретные загруженные модели в настройках. Переменные `LUMI_OLLAMA_MODEL` и `LUMI_OLLAMA_VISION_MODEL` задают необязательный приоритет модели.
- Mistral API остаётся необязательным облачным провайдером. При его недоступности приложение пробует локальную Ollama.
- Подбор модели — рекомендация, а не гарантия производительности: фактическое потребление зависит от квантования, контекста и других запущенных программ.
- Настройки и история диалогов сохраняются в `%LOCALAPPDATA%\LumiAI`.
