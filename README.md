# LUMI AI

LUMI — локальный голосовой помощник с чатом, озвучиванием ответов и базовым управлением компьютером.

## Запуск на Windows

1. Установите Python 3.11 и [Ollama](https://ollama.com/). Установщик Python должен добавить команду `py` в Windows.
2. Запустите `launch.bat`. Скрипт создаст отдельную `.venv311` на Python 3.11, установит зависимости и откроет GUI.
3. В настройках выберите **Ollama (локально)** и нажмите **Обновить список моделей Ollama**. Для автоматического выбора достаточно оставить модели в положении **Авто**.
4. Если нужных моделей ещё нет, нажмите соответствующую кнопку загрузки. Для чата предлагается `qwen2.5:3b`, для анализа экрана — `qwen2.5vl:3b`. Загрузка `ollama pull` откроется в отдельном окне CMD; дождитесь её завершения, обновите список и сохраните настройки. API-ключи не нужны.

При первом нажатии кнопки микрофона LUMI загрузит локальную модель распознавания faster-whisper (`small`); для загрузки нужен интернет, но ключ не нужен. LUMI калибрует шум и использует выбранный микрофон. После загрузки аудио распознаётся на компьютере и не отправляется в Google или другой облачный сервис. Модели и настройки хранятся в `%LOCALAPPDATA%\LumiAI`. Чтобы выбрать другую модель Whisper, задайте переменную `LUMI_WHISPER_MODEL` до запуска.

В режиме без ключа кнопка микрофона включает непрерывное прослушивание. Для активации по ключевому слову можно отдельно настроить Porcupine. Ответы озвучиваются локальной моделью Силеро с голосом «Ксения»; модель загружается при первом ответе без запроса подтверждения в консоли. Микрофон приостанавливается на время озвучивания LUMI и короткую паузу после него, чтобы ассистент не распознавал собственный голос и не отвечал по кругу. В настройках можно переключиться на женский системный голос Windows. Кнопка динамика в сообщении чата ставит ответ в очередь озвучивания.

## Экран и управление

- Кнопка с изображением глаза в чате отправляет снимок выбранного экрана найденной локальной vision-модели Ollama. Основной монитор выбирается автоматически; монитор можно сменить в настройках. Снимок не отправляется в Mistral или другие облачные сервисы.
- Локальный OCR EasyOCR используется для поиска текста при голосовых командах управления курсором и загружает свои модели при первом использовании.
- Голосовые команды «наведи на …» и «нажми на …» ищут текст на экране и перемещают курсор или выполняют один щелчок.
- Команды «что на экране?» и «прочитай экран» отправляют снимок экрана локальной vision-модели Ollama.

Снимок экрана используется только для ответа на запрос и не сохраняется в истории чата. Локальная модель может пользоваться инструментами для просмотра экрана, запуска разрешённых приложений, щелчка по найденной надписи, ввода текста и ограниченного набора клавиш. Инструменты вызываются только по явной просьбе пользователя; команды запуска программ ограничены белым списком. Ответ ассистента постепенно появляется в чате и после завершения сохраняется в истории.

## Окно и трей

Сворачивание и закрытие окна скрывают его в системный трей. Выберите **Развернуть LUMI**, чтобы вернуть окно, или **Выход**, чтобы полностью закрыть приложение.

Для сборки Windows EXE запустите `build_exe.py`; EXE и трей используют `app_icon.ico`, а окно — его квадратную PNG-версию.

## Примечания

- Для локального чата Ollama должна быть запущена. При выборе **Авто** LUMI находит загруженные модели через Ollama и выбирает одну для чата и отдельную модель с поддержкой изображений для анализа экрана. Можно также выбрать конкретные загруженные модели в настройках. Переменные `LUMI_OLLAMA_MODEL` и `LUMI_OLLAMA_VISION_MODEL` задают необязательный приоритет модели.
- Mistral API остаётся необязательным облачным провайдером. При его недоступности приложение пробует локальную Ollama.
- Настройки и история диалогов сохраняются в `%LOCALAPPDATA%\LumiAI`.
