# 🌙 LUMI AI

**Голосовой помощник, который живёт на твоём компьютере, а не в облаке.**

Скажи «Люми» — и она услышит. Ответит голосом, посмотрит на твой экран,
откроет YouTube, найдёт товар, прочитает текст с картинки и расскажет погоду.
По умолчанию всё работает локально: ни аудио, ни скриншоты никуда не улетают.

## Почему LUMI — это приятно

- 🎙️ **Полностью локальный голос.** Распознавание — faster-whisper, озвучка — Silero / Piper / голос Windows. Аудио не отправляется в Google и другие облака.
- 👁️ **Видит экран.** «Что на экране?» — локальная vision-модель опишет. «Прочитай текст на экране» — OCR найдёт и озвучит.
- 🖱️ **Управляет ПК — но безопасно.** Открывает приложения из белого списка, ищет в Google и YouTube, запускает игры в Steam, кликает по надписям. Никаких паролей, покупок и произвольных команд в CMD.
- 💬 **Красивый чат.** Стеклянный тёмный UI, несколько независимых бесед, потоковые ответы, кнопка «глаз» для снимка экрана.
- 🧩 **Навыки.** Встроенные команды с переключателями + свои собственные навыки.
- 🌤️ **Погода без ключей.** Open-Meteo, город по голосу или по IP.
- 🤫 **Живёт в трее.** Закрыл окно — LUMI осталась рядом.

## 🚀 Быстрый старт (Windows)

1. Установи **Python 3.11** (галочка «Add to PATH», чтобы работала команда `py`) и **[Ollama](https://ollama.com)**.
2. Запусти **`launch.bat`** — он сам создаст окружение `.venv311`, поставит зависимости и откроет LUMI.
3. В настройках выбери **Ollama (локально)** и оставь модели на **Авто** — LUMI сама найдёт установленные модели и подберёт подходящие под твою память.

Всё. Нажми кнопку микрофона и скажи: *«Какая погода в Москве?»*

> 💡 **Нет моделей?** В настройках есть каталог Qwen2.5 / Qwen2.5-VL с оценками памяти — скачивание в один клик. Или вручную: `ollama pull qwen2.5` (чат) и `ollama pull qwen2.5vl` (анализ экрана).
>
> 🎤 **Первый запуск голоса:** LUMI скачает модель Whisper (нужен интернет один раз, ключ не нужен) и откалибрует микрофон в фоне. Дальше — всё офлайн.
>
> 💻 **Слабый ПК (<8 ГБ RAM)?** LUMI предложит облачный Mistral API (нужен свой ключ) или компактную `qwen2.5:1.5b`. Управление компьютером даже с Mistral остаётся на локальной Ollama.

## 🗣️ Что можно сказать

| Команда | Что произойдёт |
|---|---|
| «Какая погода в Москве?» | Погода через Open-Meteo (без города — определит по IP) |
| «Что на экране?» / «Прочитай экран» | Снимок экрана → локальная vision-модель |
| «Прочитай текст на экране» | Локальный OCR EasyOCR + озвучка |
| «Наведи на …» / «Нажми на …» | Найдёт надпись на экране и наведёт курсор / кликнет |
| «Открой YouTube и найди собак» | Откроет браузер и выполнит поиск |
| «Найди лучший телевизор до 40к» | Откроет Яндекс Маркет, сравнит несколько карточек через OCR |
| «Что ты умеешь?» | Перечислит включённые команды |
| «Стоп» / «Отмена» | Мгновенно остановит озвучку и генерацию — работает всегда |

Wake-word «Люми» распознаётся локально через Whisper (без ключей, но прожорливее к CPU). Если настроишь Porcupine сам — LUMI умеет и с ним. В навыках есть тумблер **«Перебивать голосом»**: можно прервать длинный ответ короткой фразой.

## 🔒 Безопасность — не на словах

- Запуск программ — только по **белому списку**, действия — только по явной просьбе.
- **Никогда**: вход в аккаунты, ввод паролей, отправка форм, покупки, оплата.
- Модель **не может** исполнять произвольный текст в CMD/PowerShell.
- Снимок экрана используется только для ответа и не сохраняется в истории чата.
- В облако уходит только текст — и только если ты сам выбрал Mistral.

## ⚙️ Настройки, данные, логи

| Что | Где |
|---|---|
| Настройки и история чатов | `%LOCALAPPDATA%\LumiAI` |
| Логи | `log\lumi.log`, `chat.log`, `skills.log` (ротация 5 МБ × 5 архивов) |

Переменные окружения (задать до запуска): `LUMI_WHISPER_MODEL` (`small`/`medium` — точнее распознавание), `LUMI_OLLAMA_MODEL`, `LUMI_OLLAMA_VISION_MODEL`, `LUMI_LOG_DIR`.

## 🛠️ Если что-то пошло не так

| Симптом | Решение |
|---|---|
| Микрофон «молчит» | Windows → Параметры → Конфиденциальность → Микрофон: разреши классическим приложениям; в настройках LUMI выбери тот же физический микрофон, что и в системе |
| Ollama не найдена | LUMI сама пробует `ollama serve`; проверь, что Ollama установлена — причина ошибки будет в уведомлении и логе |
| Распознаёт неточно | Задай `LUMI_WHISPER_MODEL=small` или `medium` |
| Нет озвучки | Проверь голос в навыках; при сбое Silero/Piper LUMI откатится на системный голос Windows |
| Долго думает | Выбери модель поменьше в каталоге — оценки памяти прямо в настройках |
