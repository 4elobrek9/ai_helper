# 💎 LUMI AI — Project "Living Shard"

**LUMI AI** — персональный голосовой ассистент с локальной LLM и управлением компьютером. Философия проекта: *"Твой голос — её разум"*. Это компактный, стильный и быстрый инструмент, который всегда под рукой, но не мешает работе.

---

## 🎯 Смысл приложения

В отличие от громоздких интерфейсов, **LUMI** построена вокруг концепции **"Живого осколка" (Living Shard)**:
*   **Минимализм:** Окно размером **400x600** идеально вписывается в угол экрана.
*   **Визуальный отклик:** Интерактивные циановые волны реагируют на твой голос в реальном времени.
*   **Локальность:** Чат и команды выполняются локальной Ollama; облачный LLM API-ключ не нужен.
*   **Удобство:** Приложение легко сворачивается в трей и вызывается одной фразой.

---

## 🧠 Локальная LLM и распознавание экрана

Для локального чата и управления компьютером нужен запущенный **Ollama**:

1. Установите Ollama и запустите службу на `http://localhost:11434`.
2. Загрузите модель агента: `ollama pull qwen2.5-coder:7b`.
3. Для распознавания интерфейса установите локальную vision-модель: `ollama pull qwen2.5vl:3b`.

Чат, голосовые запросы и команды компьютеру используют локальную модель; облачный API-ключ не нужен. Основную модель, адрес Ollama и vision-модель можно переопределить переменными окружения `OLLAMA_MODEL`, `OLLAMA_API_BASE` и `OLLAMA_VISION_MODEL`.

Vision-модель необязательна для обычного чата. Без неё агент сможет попробовать локальный OCR, если установлен Tesseract.

### Управление компьютером

В чате можно попросить Lumi выполнить многошаговую задачу в приложениях Windows, браузере и файловой системе. Агент передаёт локальной модели снимок экрана, выполняет предложенные ею команды Python/PowerShell, проверяет результат и продолжает задачу до 24 шагов. Для управления экраном установите зависимости из `requirements.txt`; PyAutoGUI сохраняет аварийное прерывание перемещением курсора в угол экрана.

Команды агента запускаются с правами текущего пользователя и могут менять файлы и настройки компьютера. Используйте их только для задач, которым доверяете.

## 🚀 Быстрая установка

Я максимально упростил процесс развертывания, чтобы вам не пришлось возиться с консолью.

1. **Скачайте проект:** Склонируйте репозиторий или скачайте ZIP-архив.
2. **Запустите установщик:** Найдите в корневой папке файл **`launch.bat`** и запустите его.
3. **Дождитесь установки:** Скрипт создаст виртуальное окружение (`.venv`), установит зависимости из `requirements.txt` и запустит приложение.

## 🧠 Новая модульная voice-архитектура (vNext)

Добавлены файлы `voice_architecture.py`, `lumi_cli.py`, `lumi_config.yaml` с интерфейсами:
- `STTEngine`, `TTSEngine`, `WakeWordEngine`, `LLMProvider`.
- Асинхронный цикл: wake word -> распознавание -> LLM -> TTS -> возврат в ожидание.
- Конфиг в YAML/JSON + горячая перезагрузка конфига без рестарта.
- История диалога с ограничением контекста, настраиваемый system prompt, опциональный кэш ответов.
- CLI режимы:
  - `python lumi_cli.py --mode show-config`
  - `python lumi_cli.py --mode chat`
  - `python lumi_cli.py --mode voice`

### Локальные движки
- **Wake Word**: Porcupine в основном приложении; для него нужен Picovoice AccessKey.
- **TTS**: pyttsx3 (офлайн).
- **LLM**: только Ollama; модель по умолчанию `qwen2.5-coder:7b`.

> Чат и управление компьютером в приложении используют локальную Ollama; голосовая архитектура CLI не переключается на облачные LLM-провайдеры.
